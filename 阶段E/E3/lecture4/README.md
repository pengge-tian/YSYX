## 练习 3：原地替换的大陷阱
* **为什么不能用 `sed s/REGEX/SUB/ file > file`**：
  Shell 会在执行 `sed` 之前，先优先处理重定向 `>`，直接将原文件清空为 0 字节。导致 `sed` 读取到一个空文件，原始内容永久丢失。
* **正确做法**：使用 `sed -i` 原地修改选项，或者先写入临时文件再使用 `mv` 原子替换。

## 练习 4 & 5：系统开机日志排查 (`boot_analysis.sh`)
* 用 `journalctl -q` 和正则捕获组提取实际开机秒数，结合 Python `statistics` 计算平均值、中位数和极值。
* 用 `journalctl -o cat` 剥离动态时间戳，结合 `sort | uniq -c` 和 `awk '$1 != 3'` 筛选出开机间的差异日志。

## 练习 6：网络数据跨列处理 (`dataset_stats.sh`)
* 结合 `curl`、`awk`、`sort -n` 与 `sed -e 1b -e '$!d'`，实现了无临时变量直接提取列极值与差值累加。
